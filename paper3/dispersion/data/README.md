# Experimental Data

Place real experimental datasets in this directory.

Recommended formats:

- CSV
- TSV
- JSON

Do not overwrite the demonstration data embedded in the validation
scripts.

Each dataset should include enough metadata to establish:

- physical units,
- measurement uncertainty,
- experimental configuration,
- source/reference,
- calibration information.

A numerical fit without dimensional and experimental metadata is not
treated as an independent Lambda measurement.
