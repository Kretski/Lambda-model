# Real Experimental Data

This directory is reserved for externally sourced experimental data.

No independent experimental dataset is currently included.

## Preferred format

CSV:

    k,omega,uncertainty

Example:

    0.10,0.1012,0.0010
    0.20,0.2041,0.0012
    0.30,0.3098,0.0014

The example above is illustrative only and is not experimental data.

## Requirements

Each dataset should include provenance information:

- source
- authors
- publication
- DOI
- original units
- measurement uncertainty
- acquisition information

Raw data and processed data must be stored separately.
