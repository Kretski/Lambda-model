\# EXP C comparison plan (fixed before any EXP C data)



1\. Matching: for each m, model poles are ordered by Re f (q = 1, 2, ...) and matched to the

&#x20;  reference values of the same m in the same order. No re-matching by proximity.

2\. Reported for every matched pair: Re f difference (Hz and %), and Im f difference where the

&#x20;  reference gives it. Unmatched poles on either side are listed, not dropped.

3\. The comparison is reported separately for (a) the authors' model resonances and (b) measured

&#x20;  peak frequencies, depending on what the reference file contains. (a) tests the

&#x20;  implementation; (b) tests the model.

4\. No pass/fail threshold is claimed; the result is descriptive (median and maximum differences,

&#x20;  and their trend with m).

5\. Any later analysis (parameter uncertainties C ± 3 mm²/s, Omega ± 0.01 rad/s; other r\_B) is

&#x20;  labelled post hoc.
