# Archive — superseded work

Files in this folder are kept for provenance only and are not current results.

In particular, the BEC "Level A / Level B" analyses (level_a_ozeri2002/,
bec_validation/, PAPER3_ADDENDUM_BEC_LEVEL_B.md) interpreted the BEC quartic
term Lambda = xi^2/4 as support for the Lambda-model. That interpretation is
withdrawn: xi^2/4 is the standard Bogoliubov quantum-pressure term, not an
independent test. The current BEC analysis is paper3/bec_validation/steinhauer2002/.
