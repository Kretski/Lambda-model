## Supplement: q=3/q=4 closure test on the unassigned deep-pole branch (Stage 5I-32)

*This supplement documents a closure test on the last unexplored
numerical possibility for a q=3/q=4 correspondence, following the
unresolved status recorded above. It is additive — it does not change
the q=1/q=2 result and does not reopen the branch-selection discipline
established there.*

### What was tested

The unassigned deep pole first found at m=-14 in the blind 2D discovery
(10.649226 − 1.481607i) was continuation-tracked, experiment-blind,
across the full range m=-4 to m=-21, anchored at an independently
re-confirmed point at m=-12 (10.244066 − 1.635369i). Same discipline as
the q=2 Root-B continuation: each step seeded only from the immediately
preceding accepted root; experimental q3/q4 values used only in a final
post-hoc comparison, never as a seed or selection criterion.

### Result

The branch was recovered cleanly (|Res| ~ 1e-15–1e-16 throughout) across
m=-4 to m=-14 (11 points). Continuation past m=-14 toward m=-21 did not
converge under the same seeding strategy, including with a widened
complex-plane search — the branch was not located beyond this point with
the tested method.

Post-hoc comparison, m=-4 to m=-14:

| m | branch Re (Hz) | rel. error vs q3 | rel. error vs q4 |
|---:|---:|---:|---:|
| -4 | 9.310 | 28.65% | 20.97% |
| -6 | 9.369 | ~24% | ~17% |
| -8 | 9.570 | ~18% | ~13% |
| -10 | 9.876 | ~11% | ~8% |
| -12 | 10.244 | ~7.3% | ~4.2% |
| -14 | 10.649 | 6.33% (best) | 3.26% (best) |

Mean relative error across the recovered range: 13.69% (vs q3), 9.04%
(vs q4). No point comes within 1% of either experimental curve.

### Interpretation

The error decreases monotonically as |m| increases, so a closer approach
at m<-14 cannot be excluded — that region remains genuinely untested, not
ruled out. Within the tested range, the branch does not match q3 or q4
at anywhere near the precision of the q=1/q=2 result (0.01–0.06%). This
is reported as a closed, honest null result for the tested range: this
specific mathematical branch is not q3/q4, without claiming to have
ruled out q3/q4 existing elsewhere in the model's spectrum.

### Explicit non-conflation note

The chain break near m=-14 on this branch occurs in a similar numerical
neighborhood to the separately-documented Root-B continuation
termination near m_c≈-14.79 (a different branch, different (Re, Im)
values, found by a different continuation history). No relationship
between the two has been demonstrated — no bifurcation, merging, or
shared mechanism has been shown. Until such a mechanism is explicitly
established, these are reported as two separate numerical observations,
not a single confirmed phenomenon.

### Updated q=3/q=4 status

q=3/q=4 correspondence remains **unresolved**. Three independent lines
of inquiry have now been closed without finding a match: (1) continuation
from the validated q=2 Root-B branch (Stage 5I-27), (2) the v6
discovery-grid candidates (found to be Root-A-adjacent, not a distinct
q=3 branch), and (3) the unassigned deep-pole branch (this supplement).
No further search is planned absent a new candidate branch or a
change in method. This is recorded as a stable, closed line of inquiry
for this project — not as a failure of the q=1/q=2 result, which is
unaffected.
