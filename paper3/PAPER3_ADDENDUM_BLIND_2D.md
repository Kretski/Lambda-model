Paper 3 — Blind 2D Discovery Addendum

Purpose

This addendum documents an additional blind two-dimensional discovery analysis performed as a supplementary test of the Λ-model framework.

The analysis is not intended to replace the primary Paper 3 validation pipeline. It is recorded separately so that the provenance, assumptions, and interpretation of the additional test remain explicit.

Scope

The purpose of the blind 2D analysis is to examine whether the structure associated with the Λ-model can be recovered from the supplied data without directly imposing the final Λ-dependent functional form as the fitting result.

The test is therefore treated as a structural consistency check rather than as an independent measurement of a fundamental physical constant.

Relation to the Paper 3 model

The Paper 3 framework is based on the quartic dispersion relation

ω(k) = c k √(1 + Λ k²)

with the corresponding propagation modification represented through the Λ-dependent phase evolution.

The blind analysis is supplementary to this framework. Its role is to test whether the relevant structure can be recovered from the data under a less explicitly constrained representation.

Interpretation

A successful recovery is evidence that the observed structure is compatible with the model parameterization used in Paper 3.

It does not, by itself, establish that Λ represents a new fundamental physical interaction.

The appropriate interpretation is therefore:

blind structural consistency test

rather than:

independent discovery of new physics

Relation to the GW analysis

The blind 2D analysis should be considered complementary to the GW matched-filter work already documented in this repository.

The GW pipeline tests the Λ-dependent propagation model against gravitational-wave strain data and includes injection/recovery and off-source validation.

The blind 2D analysis addresses a different question: whether the relevant low-dimensional structure can be recovered without directly hard-coding the final Λ-model form into the discovery step.

These two analyses therefore provide different forms of validation and should not be treated as statistically independent measurements unless their data, preprocessing, and inference procedures are demonstrated to be independent.

Current status

Status: supplementary analysis

Claim level: structural consistency

Physical interpretation: not independently established

The results should not be described as a confirmed detection of non-zero Λ.

Reproducibility

The numerical values, plots, and intermediate outputs associated with this addendum should be retained in the repository together with the exact analysis configuration used to obtain them.

Where a result is subsequently updated, the previous result should remain traceable through the repository history rather than being silently overwritten.

Relationship to the main validation status

This document supplements, but does not supersede:

"paper3/PAPER3_VALIDATION_STATUS.md"

The main validation-status document remains the authoritative summary of the validated Paper 3 results.

Scientific claim boundary

The strongest defensible statement from this addendum is that the additional blind analysis provides a consistency check on the mathematical structure investigated in Paper 3.

It should not be used alone to claim:

- detection of a non-zero Λ;
- confirmation of a new fundamental interaction;
- an independent gravitational-wave constraint;
- exclusion of General Relativity;
- or experimental confirmation of the underlying physical interpretation.

Any such claim would require additional independent observational evidence.

Provenance note

This addendum is intentionally maintained as a separate record so that future analyses can distinguish the original Paper 3 validation results from subsequent exploratory or supplementary tests.
